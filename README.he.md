## התקנה ושימוש

1. מורידים את [המתקין](downloads/v0.1.0/Orbit-Gift-0.1.0-x64.exe) למחשב Windows x64.
2. פותחים את המתנה בגרירה או בכפתור.
3. בוחרים אם רוצים קיצור על שולחן העבודה והפעלה עם הכניסה ל־Windows. שתי האפשרויות מתחילות כבויות.
4. לוחצים על התקנה, ואז פותחים את Orbit.
5. בוחרים חלון, מחזיקים Ctrl ימני לרגע, מזיזים לכיוון הרצוי ומשחררים.

ההתקנה היא למשתמש הנוכחי, בתיקייה `%LOCALAPPDATA%\Programs\Orbit`, בלי הרשאות מנהל, חשבון או הורדות נוספות. Windows עשוי להציג אזהרת מפרסם לא מוכר בגלל היעדר חתימה.

| פעולה | קיצור |
| --- | --- |
| פתיחת טבעת הפריסות | לחיצה ממושכת על Ctrl ימני |
| חצי מסך | כיוון ימינה או שמאלה |
| רבע מסך | אחת הפינות |
| הגדלה או מירכוז | למעלה או למטה |
| מעבר בין גדלים | גלגלת העכבר |
| מעבר בין מסכים | Tab או Shift+Tab |
| פתיחה עם המקלדת | Win + Alt + Space |
| ביטול | Esc |
| החזרת השינוי האחרון | Win + Alt + Z |

האייקון ליד השעון פותח את ההגדרות. אפשר להגדיר מקש הפעלה, זמן החזקה, מרווח והפעלה אוטומטית. [המדריך הטכני](docs/TECHNICAL.md) כולל את כל האפשרויות, הסרה ואבחון תקלות.

## בנייה מהקוד

נדרשים Rust מגרסה 1.93, כלי MSVC, כלי הבנייה של Visual Studio עם Desktop development with C++ ו־Windows SDK.

```powershell
cargo build --locked --release
powershell -NoProfile -File scripts/check.ps1
powershell -NoProfile -File scripts/build-gift.ps1
```

האפליקציה נוצרת ב־`target/release/orbit.exe`, והמתקין ב־`dist/Orbit-Gift-0.1.0-x64.exe`. בנייה אוטומטית ב־Windows ובדיקות סטטיות אינן מחליפות בדיקת התקנה ושימוש אמיתית.
