Orbit · מתנה מספי
=================
קצת יותר סדר. קצת פחות גרירות.

איך פותחים את המתנה?
1. פותחים את Orbit-Gift-0.1.0-x64.exe במחשב Windows x64.
2. גוררים את נייר העטיפה מימין לשמאל. אפשר גם ללחוץ "או אפשר גם להתקין בלי להרוס את עטיפת המתנה".
3. בוחרים אם רוצים קיצור על שולחן העבודה והפעלה עם כניסה ל־Windows.
   שתי האפשרויות אינן מסומנות כברירת מחדל. בהתקנה חוזרת נשמרות הגדרות קודמות.
4. לוחצים "התקנה", ואז "פתח את Orbit".

איך משתמשים?
פותחים חלון שרוצים לסדר. מחזיקים Ctrl ימני לרגע, מזיזים את העכבר לכיוון
הרצוי בטבעת ומשחררים. ימין ושמאל לחצי מסך, פינות לרבעים ולמעלה להגדלה.
אפשר גם Win + Alt + Space ואז חיצים ו־Enter.
Esc מבטל. Win + Alt + Z מחזיר את השינוי האחרון.
בהפעלה הראשונה ייפתח חלון הגדרות. האייקון ליד השעון מחזיר אליו תמיד.

ההתקנה מקומית, למשתמש הנוכחי, ללא חשבון או הורדות נוספות.
התוכנה מותקנת ב־%LOCALAPPDATA%\Programs\Orbit.
אפשר להסיר אותה דרך Settings > Apps > Installed apps, או Uninstall Orbit בתפריט Start.
ההגדרות והדוחות נשמרים ב־%LOCALAPPDATA%\Orbit גם אחרי הסרה.

לפני שמעבירים הלאה:
זו גרסת פיתוח 0.1.0 לא חתומה. הקבצים נבנו ונבדקו סטטית במק,
אבל ההתקנה, פתיחת התוכנה ופעולת סידור החלונות עדיין לא נבדקו במחשב Windows.
היעד לבדיקה הוא Windows 10/11 x64; גרסאות ARM ומערכות אחרות אינן כלולות.
Windows עשוי להציג אזהרת מפרסם לא מוכר. אין צורך לכבות הגנות מערכת.
אם משהו לא נפתח, מריצים Check-Windows-Startup.cmd ומעיינים בדוח.
הפרטים המלאים וקוד המקור מצורפים לחבילה.
