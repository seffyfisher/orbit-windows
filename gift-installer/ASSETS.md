# Orbit Windows gift artwork

The outside is a dense, deliberately chaotic collage of overlapping Windows application windows: Word-style document/ribbon, Cursor-style code editor, tabbed browsers, File Explorer, spreadsheet, email, Terminal, calendar and other desktop tools. The collage is printed on cobalt wrapping paper, preserving physical folds, grain and alpha transparency. These are generated illustrative interfaces, not captured user documents or live software screenshots.

`assets/wrapped-parcel.png` and `assets/paper-flap.png` were edited with built-in Imagegen on 2026-10-16. Complete prompts are in `windows-chaos-prompts.json`. The strip uses large partial application-window fragments to maintain print scale when drawn small. The blue keyboard print has been replaced throughout.

`assets/product-box.png` retains the original calm white Orbit box and blue O wordmark, revealed by tearing away the busy exterior. `assets/dedication.png` retains the approved blue handwritten באהבה, מספי and corrected letter spacing.

The displayed parcel is 420×210 logical pixels, half the original width. All internal layers and the curled strip scale proportionally. Native and browser copies use the same art and gesture geometry. The browser is a simulation only. Windows runtime acceptance remains pending.
